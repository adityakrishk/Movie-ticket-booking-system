PROBLEM STATEMENT

The Movie Ticket Booking System is a console-based application designed to simplify the process of booking movie tickets. In a traditional booking process, customers may need to manually check movie details, showtimes, seat availability, and calculate ticket and food costs. This project provides a simple computerized system where users can select a movie, choose a showtime, select available seats, add food and drinks, and calculate the total booking cost. The system also prevents already booked seats from being selected again for the same movie and showtime.

SCOPE OF THE PROJECT

The scope of this project is to provide a basic movie ticket booking system using Python. The system manages a list of movies, showtimes, seats, ticket prices, and food items. Users can view available movies, select showtimes, book multiple seats, purchase food and drinks, and confirm or cancel their booking. The project is intended for basic console-based booking and does not include online payment, user accounts, databases, real-time cinema integration, or online booking.

TARGET USERS

The main target users of this system are:

Movie customers who want to book tickets and select seats.

Cinema staff who want a simple system for managing basic bookings.

Students and beginners who want to understand how a movie booking system can be developed using Python.

Small cinema or classroom project environments requiring a simple ticket booking application.

HIGH-LEVEL FEATURES

View available movies with their duration and ticket prices.

View available showtimes.

Select a movie and showtime.

Display available and already booked seats.

Book multiple seats in a single booking.

Prevent booking of already reserved seats.

Enter and display the customer's name.

Select food and drinks with quantities.

Automatically calculate ticket and food costs.

Display a complete booking summary.

Confirm or cancel a booking.

Maintain separate booked seats for each movie and showtime.

Provide a simple main menu for viewing movies, booking tickets, and exiting the system.
