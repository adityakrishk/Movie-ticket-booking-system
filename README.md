#Movie Ticket Booking System

A simple Python-based Movie Ticket Booking System.

#Features

View available movies

Select movie and showtime

Select and book seats

Order food and drinks

Calculate total price

Confirm or cancel booking

#Requirements

Python 3.x

No additional libraries are required.

#How to Run

Make sure Python is installed.

Open the folder containing main.py.

Double-click main.py or right-click and select Open with Python.

You can also run it from Command Prompt:

python main.py


#If that does not work, try:

py main.py

#Note

Bookings are stored temporarily while the program is running. All bookings will be cleared when the program is closed.
